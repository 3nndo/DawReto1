Our goals

We are a group whose purpose is to make it easier to create and manage sporting events, sustainable events, or both. With EcoShark, we can work together to make our planet a better place by supporting everyone's well-being and health. To achieve this, we have set short- and long-term goals to improve our project and make it easier to help the environment.

 

Improve the website

Our website is currently static: it is a prototype of what we ultimately want to build. We plan to add interactive features in the future.

Recruitment

We currently have only a few people working towards this goal, but our team is gradually growing. We are counting on you to join this project and contribute your part.

 

Expansion

We aspire to become an international platform. We plan to make it multilingual so it can be used beyond Spain, without limits imposed by borders.

Collaboration

We want to support not only sustainability initiatives, but also people in need through donations, whether financial contributions or food collections.
